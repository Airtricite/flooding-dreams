# Flooding Dreams · 洪梦

洪水逃生关卡游戏 —— **纯前端引擎源码（HTML 版）**。

浏览器直接运行，无构建步骤、无打包器：原生 ES Modules + three.js + cannon-es。

> 本仓库是「**无扩充素材 / 无内置关卡**」的精简版，只包含可运行的 Web 引擎与编辑器源码。

## 包含内容

- **游玩**：第一 / 第三人称洪水逃生关卡，含检查点、道具、机制方块、液体、传送门等
- **关卡编辑器**：事件编辑器、动画编辑器、贴图修改器、矢量图编辑器、预制件工具箱、关卡包
- **回放**：每局自动录制成回放，支持第一人称 / 电影级运镜剪辑与镜头表导出
- **角色皮肤**：给 glb / gltf 角色涂画皮肤、挂挂件

## 目录结构

```
index.html                  入口
sw.js                       Service Worker（纯静态托管下的缓存绕行）
.flooding_dreams/
  js/                       引擎源码（ES Modules，见下）
  styles/                   样式
  vendor/                   three.js / cannon-es 及 addons（已内置，离线可用）
  serve.py                  本地服务器 + 存档 API（推荐用它启动）
```

`js/` 主要模块：

```
core/     引擎底座：渲染管线 / Worker 池 / 存储 / 材质 / 后处理 / 天空 / 粒子预设
world/    关卡构建：物体、几何、液体、机制、事件、动画、画笔
player/   角色控制、相机、工具
game/     会话、大厅、NPC、回放播放器、电影运镜
editor/   编辑器全部面板与子编辑器
ui/       界面：菜单、关卡列表、HUD、设置、回放列表
gen/      程序化关卡生成（模拟退火 + 程序化装饰）
levels/   关卡注册表与关卡包（本版本内置关卡已清空）
i18n/     多语言文案
```

## 运行

需要 **Python 3**：

```bash
python .flooding_dreams/serve.py 8010
```

浏览器打开 <http://localhost:8010/> 。

`serve.py` 除了静态托管，还提供两件事：

- **存档 API**：存档落到 `.flooding_dreams/saves/`（一个关卡 = 一个文件夹，自带素材），换端口 / 换浏览器都能读到同一份
- **自动版本号**：给 `index.html` 与每个 `.js` 的 import 加上 `?v=`，改完代码刷新即生效，不会新旧模块混用

也可以直接丢到任意静态托管（如 GitHub Pages）。此时存档走浏览器本地存储，缓存绕行由 `sw.js` 负责。

## 关于「无扩充素材 / 无内置关卡」

- **扩充内置素材**（CC0 贴图 + HDR 全景图）不在本仓库。缺失时引擎会自动降级：清单读不到 → 扩充素材入口静默隐藏，关卡里遗留的 `asset:bi/…` 引用按「已丢失」处理，**不影响启动与编辑器使用**。
- **内置关卡**为空：`js/levels/builtin.js` 里的关卡工厂为 `FACTORIES = []`，所以「关卡选择」里没有官方关卡。导出 API 全部保留，引擎照常运行。
- 不含 `saves/`（本地存档）、Electron / Android 打包壳与构建脚本。

## 添加自己的关卡

1. 打开游戏 → **关卡编辑器** → 做好关卡 → **导出** 得到 `.fdlevel`（本质是 JSON）
2. 放进 `.flooding_dreams/js/levels/custom/`
3. 在 `.flooding_dreams/js/levels/custom/index.json` 里写上文件名，例如：

   ```json
   ["我的关卡.fdlevel"]
   ```

重新载入后即出现在「关卡选择」中，标记为「自定义」。

## 技术要点

- **无构建**：源码即产物，改完刷新即可，没有 webpack / vite 之类
- **渲染线程解耦**：主线程处理逻辑，渲染可在独立 Worker 中执行
- **Worker 池**：关卡生成、列表加载等重活并行计算
- **程序化关卡**：模拟退火迭代演化世界结构 + 程序化装饰
- **素材本地化**：一个关卡一个文件夹，导入的素材自动拷贝进该关卡目录，可整体拷走
